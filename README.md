# K M Ahbab Zaman Aqib | Academic Portfolio

Personal portfolio of an undergraduate researcher in agriculture at Sylhet Agricultural University, Bangladesh. The work centers on salinity stress tolerance in rice, plant bioinformatics and molecular docking.

**Live site:** https://aqib-17.github.io

## Sections

About and research interests, education, experience, projects, publications, skills and tools, leadership and certifications, contact and references.

## Tech

Plain HTML, CSS and JavaScript in a single `index.html`. No build step. Light and dark themes, responsive layout, keyboard-accessible navigation.

## Repository structure

```

    └── AQIB_ATS_CV.pdf
```

- `dev`: work in progress; merge into `main` when ready

Open `index.html` in a browser.
